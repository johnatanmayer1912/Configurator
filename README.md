# NX-OS Configuration Authority

Web-based configurator for Cisco Nexus switches with vPC domain management, multi-switch configuration, and offline deployment capabilities.

## Version
6.44.0

## Features
- Multi-switch configuration editor
- vPC domain management with validation
- Template-based deployment
- Offline executable generation
- Comprehensive error handling and validation

## Quick Start
```bash
python main.py
```

## Build Executable
```bash
build_exe.bat
```
