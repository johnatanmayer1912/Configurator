# UI/UX Excellence

1. Wizard steps must be clear. Show progress indicators.
2. Visual hierarchy must guide attention. Important actions first.
3. Forms must be accessible. Use labels, ARIA, keyboard navigation.
4. Multi-switch editor must be consistent. Same behavior everywhere.
5. Error messages must be helpful. Explain what went wrong and how to fix.
6. No confusing flows. One action per screen when possible.
7. Loading states must show progress. No frozen screens.
8. Success states must celebrate. Confirm completion clearly.
9. Responsive design. Works on all screen sizes.
10. If the current task needs deeper help in another area, immediately invoke the matching skill before continuing.
