# Core Programming Principles

1. Read existing code before modifying. Understand patterns.
2. Single responsibility. Each function does one thing.
3. DRY principle. Extract common patterns.
4. KISS principle. Keep it simple.
5. YAGNI principle. Don't build for hypothetical futures.
6. Use descriptive names. No abbreviations unless obvious.
7. Validate inputs. Handle null/undefined explicitly.
8. Build small, independent modules. Clear interfaces.
9. Commit frequently. Write meaningful commit messages.
10. Before any action: Check if a skill should be invoked. Invoke it.
