# Efficiency & Git Excellence

1. Measure before optimizing. Profile first. Identify bottlenecks.
2. Cache expensive operations. Use appropriate cache invalidation.
3. Use async/await for I/O. Never block on network calls.
4. Avoid memory leaks. Clean up resources. Use streams for large data.
5. Optimize build pipeline. Cache dependencies. Parallelize tasks.
6. Branch naming: type/description (feature/add-auth).
7. Commit messages: Conventional commits. Format: type(scope): description.
8. Commit frequently. Small, focused commits. One logical change per commit.
9. PR description: Describe what changed and why. Link to issues.
10. If the current task needs deeper help in another area, immediately invoke the matching skill before continuing.
