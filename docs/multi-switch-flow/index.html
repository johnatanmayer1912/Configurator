System Architecture Overview

User Launches Application → Main Page Load → User Selects Mode
    ↓
    ├─→ Quick Mode → Single-Switch Wizard
    └─→ Multi-Switch Mode → Template Gallery → Template Selection
            ↓
            Template Success Screen
            ↓
            ├─→ Customize Network → Configuration Editor → Generate Config
            └─→ Generate Config (Direct)
            ↓
            API Call: POST /generate-deployment → Backend Processing
            ↓
            Results Display → Success Modal → Config Files Saved
