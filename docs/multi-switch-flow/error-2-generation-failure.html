Error 2: Configuration Generation Failure

Multi-Switch User Flow Documentation - Error Handling

← Back to Index

Scenario

Backend fails to generate one or more configurations during the generation process.

Error Conditions

  • Backend Processing Error: Configuration generation fails for specific switch
  • Validation Error: Invalid configuration parameters
  • Resource Error: Insufficient system resources
  • File System Error: Cannot write config files
  • Partial Success: Some switches succeed, others fail

Expected Result

  • Warning toast appears: "Generated 3/4 configurations with 1 error"
  • Results show failed switches with error messages
  • Successful configs still saved to output directory
  • Error details shown for each failed switch
  • User can retry or fix issues

Recovery Steps

  • Review error messages - Check specific error details for failed switches
  • Fix configuration issues - Edit switch configuration in editor
  • Retry generation - Click Generate Config again after fixing
  • Remove problematic switch - Delete switch causing errors if not needed
  • Check backend logs - Review server logs for detailed error information
  • Use successful configs - Download configs that were successfully generated
