QA Testing Checklist

General Testing Guidelines

For each step, verify:

  • HTML structure matches expected
  • All buttons have correct data-action attributes
  • All ARIA attributes are present
  • JavaScript functions execute without errors
  • Expected UI state changes occur
  • Data objects update correctly
  • API calls use correct endpoints and payloads
  • Error handling works as expected
  • Toast messages appear correctly
  • Modals open/close properly

Step-by-Step Verification

Step 1: Application Launch

  • Application loads at http://127.0.0.1:9000
  • Header shows version 6.38.1
  • Offline Ready badge is visible
  • Mode dropdown shows "Mode: Quick"
  • Wizard panel shows Step 1
  • Template gallery is hidden

Step 2: Enable Multi-Switch Mode

  • Mode dropdown changes to "Mode: Multi-Switch"
  • Template gallery becomes visible
  • All templates are displayed
  • Filter buttons are present
  • Configuration editor remains hidden

Step 3: Template Selection

  • Template cards display correctly
  • Template metadata is accurate
  • Apply Template button works
  • Loading spinner appears
  • Deployment object is populated
  • Validations run successfully

Step 4: Template Success Screen

  • Success icon appears
  • Template name is displayed
  • Topology SVG renders correctly
  • Configuration summary is accurate
  • All action buttons work

Step 5A: Configuration Editor

  • Template gallery hides
  • Configuration editor appears
  • Topology canvas shows network
  • All switches are listed
  • Edit/Clone/Remove buttons work
  • Editor header buttons work

Step 5B: Direct Generation

  • Loading overlay appears
  • Deployment input is constructed correctly
  • API call is made
  • Loading overlay is removed

Step 6: Tab Navigation

  • All tabs are present
  • Tab switching works
  • Panel content updates correctly
  • ARIA attributes update

Step 7: Switch Editing

  • Edit modal opens
  • Form fields show current values
  • All fields are editable
  • Save button updates deployment
  • Cancel button closes modal

Step 8: Generate Configuration

  • API request is correct
  • Request payload is valid
  • Response is parsed correctly
  • Toast message appears
  • Results display appears

Step 9: Results Display

  • All switches are shown
  • Status badges are correct
  • Action buttons work
  • Summary is accurate
  • Open Folder button works

Step 10: Success Modal

  • Modal appears
  • Summary is correct
  • Output directory is shown
  • Created files are listed
  • All modal buttons work

Alternative Paths Testing

Path A: Manual Configuration

  • "Use Manual Configuration" button works
  • Editor appears empty
  • Add Switch button works
  • Manual configuration flow works

Path B: Change Template

  • "Change Template" button works
  • Deployment is cleared
  • Template gallery re-appears
  • New template can be selected

Path C: Save Custom Template

  • "Save as Template" button works
  • Prompt for name appears
  • Template is saved to localStorage
  • Custom template appears in gallery

Error Handling Testing

Error 1: Template Application Failure

  • Error toast appears
  • Error message is descriptive
  • Template gallery re-appears
  • Deployment is unchanged
  • Recovery options work

Error 2: Configuration Generation Failure

  • Warning toast appears
  • Partial success is shown
  • Error details are displayed
  • Successful configs are saved
  • Retry option works

Cross-Browser Testing

Test in:

  • Chrome (latest)
  • Firefox (latest)
  • Edge (latest)
  • Safari (if available)

Accessibility Testing

Verify:

  • Keyboard navigation works
  • Screen reader compatibility
  • ARIA labels are correct
  • Focus management is proper
  • Color contrast meets WCAG AA
