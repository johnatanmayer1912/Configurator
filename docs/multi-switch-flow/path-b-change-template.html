Path B: Change Template

Multi-Switch User Flow Documentation - Alternative Path

← Back to Index

Overview

This path allows users to change to a different template after initial selection.

User Action

Action: User clicks "Change Template" from template success screen

Expected Result

  • Current deployment is cleared
  • Template gallery re-appears
  • User can select different template
  • All previous configuration is lost

Flow Steps

  1. Click "Change Template" - From template success screen
  2. Deployment cleared - Current configuration removed
  3. Template gallery re-appears - Shows all available templates
  4. Select different template - Choose new template from gallery
  5. Template success screen appears - New template applied
  6. Continue with Customize Network or Generate Config - Proceed with new template

Use Cases

  • User selected wrong template initially
  • User wants to compare different templates
  • User changed requirements after template selection
  • Exploring different network topologies
