Path A: Manual Configuration

Multi-Switch User Flow Documentation - Alternative Path

← Back to Index

Overview

This path allows users to skip templates and configure switches manually from scratch.

User Action

Action: User clicks "Use Manual Configuration" from template gallery

Expected Result

  • Template gallery becomes hidden
  • Configuration editor appears with empty deployment
  • User must manually add switches, vPC domains, VLANs, uplinks
  • Topology canvas shows empty state

Flow Steps

  1. Click "Use Manual Configuration" - Skips template selection
  2. Configuration editor appears (empty) - Shows empty topology canvas
  3. Click "+ Add Switch" - Opens add switch modal
  4. Fill switch details - Enter hostname, role, model, IP, etc.
  5. Save switch - Switch added to deployment
  6. Repeat for all switches - Add all required switches
  7. Click "+ Add vPC Domain" - For vPC configurations
  8. Configure vPC pairs - Set primary/secondary switches
  9. Configure VLANs - Add VLANs in VLANs tab
  10. Configure uplinks - Add uplinks in Uplinks tab
  11. Click "Generate Config" - Generate configurations

Use Cases

  • Users who prefer manual configuration over templates
  • Custom network topologies not covered by templates
  • Testing specific configuration scenarios
  • Learning the configuration process step-by-step
