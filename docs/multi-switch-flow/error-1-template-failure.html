Error 1: Template Application Failure

Multi-Switch User Flow Documentation - Error Handling

← Back to Index

Scenario

Template application fails due to API error, validation error, or other issues.

Error Conditions

  • API Error: Backend returns error response
  • Validation Error: Port channel ID conflicts
  • Interface Format Error: Invalid interface names for model
  • Network Error: Cannot reach backend
  • Template Data Error: Invalid or corrupted template data

Expected Result

  • Error toast appears: "Template application failed: [error message]"
  • Template gallery re-appears
  • Deployment object remains unchanged
  • User can select different template or use manual configuration

Recovery Steps

  • Select different template - Choose another template from gallery
  • Use manual configuration - Click "Use Manual Configuration"
  • Check error message - Review specific error details
  • Retry template application - Try same template again (if transient error)
  • Check application logs - Review console for detailed error information

JavaScript Error Handling

try {
    // Apply template logic
    deployment = { ... };
    // ...
} catch (error) {
    console.error('[TEMPLATE_APPLY] [ERROR] Template application failed:', error);
    flashToast('Template application failed: ' + error.message, 'error');
    renderTemplateGallery(); // Restore template gallery
}
