Path C: Save as Custom Template

Multi-Switch User Flow Documentation - Alternative Path

← Back to Index

Overview

This path allows users to save their current configuration as a custom template for future use.

User Action

Action: User clicks "Save as Template" from template success screen or editor

Expected Result

  • Prompt for template name appears
  • Current deployment saved to localStorage as custom template
  • Custom template appears in template gallery
  • Template can be selected in future sessions

Flow Steps

  1. Click "Save as Template" - From template success screen or editor header
  2. Enter template name - Prompt appears for custom name
  3. Template saved to localStorage - Current deployment serialized and stored
  4. Template re-rendered - Gallery refreshes with custom template included
  5. Custom template available - Can be selected in current or future sessions

Use Cases

  • Users want to reuse custom configurations
  • Creating organization-specific templates
  • Saving frequently used network topologies
  • Building template library over time
