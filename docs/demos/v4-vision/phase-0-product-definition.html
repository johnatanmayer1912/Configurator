Product Definition (v4)

One page the team signs before writing code.

Hero customer

Lab engineer at a console or jump host. Air-gapped or offline. Needs a vPC leaf pair config for Nexus 93180 in under 5 minutes.

Hero outcome

  • Primary + secondary configs in one build
  • vPC domain, peer-link, keepalive, uplinks — no junk access ports
  • Optional server ports via Interface Planner
  • Paste-ready CLI, saved next to the exe

One sentence

“Offline vPC leaf configs for Nexus 93180 — both switches, lab-ready.”

Explicitly NOT v4.0 hero

  • Expert scenario grid on home screen
  • Config Builder paste-as-first-step
  • 5-step Mode → vPC → Speed → Configure → Review
  • 1G access closet as default path
  • VXLAN / spine-only as equal choices
  • Production cutover claims on marketing

These move to Advanced or v4.1+.
