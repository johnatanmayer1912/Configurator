## Quality Criteria

### Professional Skill Standards

A skill is considered **Professional** when it meets all criteria:

1. **Structure**: Follows skill template with required sections
2. **Capabilities**: Comprehensive capability list with specific details
3. **Activation**: Clear activation triggers and dependencies
4. **Behavioral Traits**: Defined behavioral expectations
5. **Knowledge Base**: Documented knowledge areas
6. **Response Approach**: Systematic response methodology
7. **Example Interactions**: Specific use cases
8. **Limitations**: Clear scope boundaries
9. **Integration**: Defined collaboration with other skills
10. **Documentation**: Complete and well-organized

### Enhancement Criteria

A skill is considered **Enhanced** when it meets:

1. **Structure**: Follows basic structure
2. **Capabilities**: Expanded capability list
3. **Best Practices**: Includes best practices
4. **Activation**: Basic activation triggers
5. **Partial Documentation**: Some sections complete

### Basic Skill Characteristics

A skill is considered **Basic** when it has:

1. **Structure**: Minimal structure
2. **Capabilities**: Limited capability list
3. **Missing Sections**: Lacks behavioral traits, knowledge base, response approach
4. **No Activation Rules**: Missing or minimal activation triggers
5. **No Dependencies**: Undefined skill dependencies
