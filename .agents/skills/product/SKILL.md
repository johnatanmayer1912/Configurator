# Product Skill

Focuses on building tools that simplify complex network issues for human operators.

## Best Practices
1. **Actionable Insights**: Provide clear, direct answers to "what happened" and "why it happened" instead of dumping raw CLI logs.
2. **Offline Resilience**: Design features to work seamlessly when disconnected from live target networks (e.g. paste-based analysis, offline reports, standalone executable builds).
3. **Audit Trails**: Maintain complete logs of executed commands and forensic decisions for security compliance.

## Product Strategy
- **User-Centric Design**: Focus on operator workflows and pain points
- **Market Research**: Understand customer needs, use cases, and competitive landscape
- **Product Roadmaps**: Create outcome-based roadmaps across 3 horizons (now, next, later)
- **Value Proposition**: Clearly articulate the business value and differentiation
- **Success Metrics**: Define measurable KPIs for product success

## Product Planning
- **Backlog Management**: Maintain ordered queues of work items (user stories, tasks, bugs)
- **Prioritization**: Use frameworks like RICE, MoSCoW, or value vs. effort
- **Acceptance Criteria**: Write clear, testable acceptance criteria for features
- **Sprint Planning**: Collaborate with engineering on capacity and delivery
- **Release Planning**: Coordinate releases with marketing, sales, and support

## Product Development
- **Engineering Collaboration**: Work closely with development teams on technical feasibility
- **User Research**: Conduct user interviews, surveys, and usability testing
- **A/B Testing**: Validate hypotheses with controlled experiments
- **Feedback Loops**: Establish mechanisms for continuous user feedback
- **Iterative Development**: Use agile methodologies for rapid iteration

## Product Launch
- **Go-to-Market Strategy**: Define launch plans and marketing campaigns
- **Documentation**: Ensure comprehensive user guides and API documentation
- **Training**: Provide training materials and onboarding resources
- **Support**: Establish support processes and escalation paths
- **Monitoring**: Set up analytics and monitoring for post-launch tracking

## Post-Launch
- **Performance Tracking**: Monitor KPIs and success metrics
- **User Feedback**: Collect and analyze user feedback
- **Continuous Improvement**: Iterate based on data and feedback
- **Feature Requests**: Manage and prioritize incoming feature requests
- **End-of-Life Planning**: Plan for product retirement when appropriate
